# Action Theory
## Constraint-Freedom-Roadblock as an Action-Fundamental Theory of Reality

**Research status:** speculative working theory; not established physics.

**Core hypothesis:** The primitive structure of reality is not a pre-existing universe containing matter, fields, space and time. The primitive structure is an algebra/network of admissible actions and their composition.

\[
\boxed{\text{fundamental reality}=(\mathfrak A,\circ)}
\]

where \(\mathfrak A\) is the set of elementary actions and \(\circ\) is their physical composition rule.

## Core CFR definitions

For a partial action history \(h\), let

\[
\mathcal N(h)=\{\alpha:\alpha\circ h\text{ is physically admissible}\}.
\]

Then:

\[
\boxed{\text{Constraint}=\text{restriction defining }\mathcal N(h)}
\]

\[
\boxed{\text{Freedom}=F(h)=\dim\mathcal N(h)}
\]

and

\[
\boxed{\text{Roadblock }R(h)\iff\mathcal N(h)=\varnothing.}
\]

A Roadblock terminates a particular action channel, not reality itself. A chemical reaction can finish while other processes remain possible.

## Emergent ontology

A state is an equivalence class of histories with equivalent future possibilities:

\[
h_1\sim h_2
\iff
\mathcal N(h_1)\cong\mathcal N(h_2).
\]

Therefore

\[
\boxed{\text{state}=[h]}
\]

and a persistent object is a stable equivalence class of action histories.

Proposed hierarchy:

\[
\boxed{
\text{action}
\rightarrow
\text{history}
\rightarrow
\text{state}
\rightarrow
\text{stable object/matter}
}
\]

## Quantum theory

Assign each action a complex amplitude:

\[
Z(\beta\circ\alpha)=Z(\beta)Z(\alpha).
\]

For a history,

\[
Z(\gamma)=e^{iS[\gamma]/\hbar}.
\]

The transition amplitude is

\[
\boxed{
K(X_f,X_i)=
\sum_{\gamma:X_i\to X_f}
e^{iS[\gamma]/\hbar}.
}
\]

In the semiclassical limit,

\[
\delta S=0,
\]

recovering stationary-action mechanics.

With a complex linear state space and continuous composition,

\[
\boxed{
i\hbar\frac{d}{dt}|\psi\rangle=H|\psi\rangle.
}
\]

For a nonrelativistic particle,

\[
\boxed{
i\hbar\frac{\partial\psi}{\partial t}
=
\left[-\frac{\hbar^2}{2m}\nabla^2+V\right]\psi.
}
\]

**Important unresolved point:** CFR has not yet derived why the fundamental action algebra must use complex amplitudes, the Hilbert-space norm, unitarity, and the Born rule.

## Entanglement

Independent action structures factor:

\[
\mathcal A_{AB}
=
\mathcal A_A\otimes\mathcal A_B.
\]

Entangled structures do not:

\[
\boxed{
\mathcal A_{AB}\neq
\mathcal A_A\otimes\mathcal A_B.
}
\]

CFR interpretation:

\[
\boxed{
\text{entanglement}
=
\text{nonfactorizability of fundamental action possibilities}.
}
\]

This allows spatially separated emergent systems to remain fundamentally related without requiring controllable faster-than-light signalling.

## Space and time

Time is hypothesized to emerge from causal ordering:

\[
\alpha\prec\beta
\]

when \(\beta\) is an admissible continuation of \(\alpha\).

Space is hypothesized to emerge from the geometry of mutually independent action directions.

If the large-scale action network develops a Lorentzian metric,

\[
ds^2=-c^2dt^2+dx^2+dy^2+dz^2,
\]

then the null boundary gives

\[
ds^2=0
\]

and therefore

\[
|\mathbf v|=c.
\]

Thus

\[
\boxed{
c=
\text{propagation rate of the null boundary of emergent action accessibility}.
}
\]

**Unresolved:** CFR has not yet derived the Lorentzian signature or the fact that the macroscopic dimension is four.

## Fields

A field is proposed to be a collective coarse-grained pattern of action relationships.

For a U(1) sector, introduce link variables

\[
U_{ij}\in U(1)
\]

with

\[
U_{ij}\rightarrow
e^{i\alpha_i}U_{ij}e^{-i\alpha_j}.
\]

In a continuum limit,

\[
U_{ij}
\rightarrow
\exp\left(ie\int_i^j A_\mu dx^\mu\right),
\]

giving

\[
A_\mu\rightarrow
A_\mu+\frac1e\partial_\mu\alpha.
\]

The curvature becomes

\[
\boxed{
F_{\mu\nu}
=
\partial_\mu A_\nu-\partial_\nu A_\mu
}
\]

and the effective action becomes Maxwell theory.

CFR interpretation:

\[
\boxed{
\text{electromagnetic field}
=
\text{curvature of an internal action connection}.
}
\]

The Higgs field is proposed as a collective order parameter of the vacuum action network:

\[
V(\Phi)
=
-\mu^2|\Phi|^2+\lambda|\Phi|^4.
\]

The observed nonzero vacuum configuration would correspond to a stable phase of the underlying action network.

## Matter

Matter is hypothesized to be a stable localized action pattern satisfying

\[
\frac{\delta S_{\rm eff}}{\delta\Phi}=0
\]

with a stability condition

\[
\delta^2S_{\rm eff}>0
\]

in physical, non-gauge directions.

Thus

\[
\boxed{
\text{matter}
=
\text{stable localized action pattern}.
}
\]

A particle's mass would be its invariant rest energy,

\[
mc^2=E,
\]

and its quantum numbers would arise from invariants of the underlying action structure.

A major CFR goal is therefore:

\[
\boxed{
\text{derive the particle spectrum from stable action solutions}.
}
\]

## Freedom Geometry

The main genuinely new CFR object is a metric on the space of physically admissible continuations:

\[
\boxed{\mathsf G_{AB}}.
\]

Its local freedom volume is

\[
\mathcal V_F=\sqrt{|\det\mathsf G|}.
\]

A regular action regime satisfies

\[
\mathcal V_F>0.
\]

A Roadblock candidate is

\[
\boxed{

The central conjecture is therefore:

\[
\boxed{

Introduce a CFR correction

\[
\boxed{
G_{\mu\nu}+\Lambda g_{\mu\nu}
=
\frac{8\pi G}{c^4}T_{\mu\nu}
+

The key research target is to derive \(\mathcal K_{\mu\nu}\) from the microscopic action algebra rather than assume it.

A possible application would be a controlled modification of gravitational response. This is the mathematical route by which a CFR “antigravity engine” could exist, but no such technology is currently established.

Every ingredient must be classified as:

\[

\text{assumed},
\quad
\text{effective},
\quad
\text{or predicted}.
